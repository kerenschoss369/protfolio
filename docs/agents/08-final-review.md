# Agent 08 — Final Product Review

You are the final reviewer: senior frontend architect, product designer, technical recruiter, and content fact-checker.

Read:

- `docs/portfolio-spec.md`
- `docs/content-decisions.md`
- `docs/design-system.md`
- `docs/implementation-plan.md`

Do not begin by making changes. Audit first.

## 1. Product review

Evaluate whether the portfolio feels:

- Premium
- Original
- Precise
- Technically credible
- Visually sophisticated
- Responsive
- Fast
- Accessible
- Personal without being informal
- Interactive without being distracting

Identify generic or unfinished areas.

## 2. Fact review

Verify:

- No invented metrics
- No invented employer claims
- No fake URLs
- No fake screenshots
- No false solo-project claims
- No discovery claim for ATLAS
- No confidential EL AL detail
- No medical usability implication
- Clinical limitation remains visible
- Simulations are labeled
- Repository visibility is not assumed

## 3. Cross-route review

Review:

- Homepage
- Work index
- Every project
- About
- Contact
- Not-found
- Mobile menu
- Command menu
- Theme behavior

## 4. Responsive review

Check:

- 320
- 375
- 430
- 768
- 1024
- 1280
- 1440
- 1920

Look for:

- Horizontal overflow
- Clipped text
- Broken diagrams
- Tiny touch targets
- Poor hierarchy
- Hover dependence
- Code overflow
- Unreadable metadata

## 5. Interaction review

Check:

- Keyboard access
- Focus order
- Escape
- Focus restoration
- Reduced motion
- Touch behavior
- No autoplay sound
- No blocked content
- No accidental scroll hijacking

## 6. Engineering review

Run:

- Formatting
- Lint
- Type check
- Unit tests
- E2E tests
- Production build

Inspect:

- Console errors
- Hydration warnings
- Dead code
- Unused dependencies
- Secrets
- Broken links
- Missing metadata

## 7. Final changes

Fix only evidence-backed issues.

Do not redesign functioning areas purely from preference.

## 8. Final report

Provide:

1. Product-quality assessment
2. Facts and confidentiality confirmation
3. Accessibility result
4. Responsive result
5. Performance result
6. Commands and outcomes
7. Files changed
8. Remaining missing real-world content
9. Remaining known limitations
10. Recommended deployment checklist

Do not claim perfection. Be specific and honest.
